## <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/linux/linux-original.svg" width="22" height="22" valign="middle" /> Competencias Adquiridas

* **Fundamentos de JS (ES6+)**: Variables (`let`, `const`), tipos de datos, operadores lógicos y numéricos.
* **Estructuras de Control**: Condicionales (`if/else`, `switch`) y ciclos de repetición (`for`, `while`).
* **Modularidad y Funciones**: Declaración de funciones, parámetros, valores de retorno y arrow functions.
* **Manipulación del DOM & Eventos**: Selección de elementos HTML, modificación dinámica de contenido/CSS y manejo de eventos de usuario.
